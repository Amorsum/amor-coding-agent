# ADR 0001：首个迭代采用确定性垂直切片

## 状态

已接受。

## 决策

首个迭代只支持 Python 示例仓库。系统使用自建显式状态机、Git worktree、本机受控子进程、JSONL 轨迹和独立 Verifier。真实 LLM Provider 暂不进入验收链路，改由脚本化 Agent 驱动同一套工具接口。

## 原因

先证明工作区隔离、工具策略、补丁、验证和可重放证据链能够稳定协作，之后才能判断模型策略的真实效果。脚本化 Agent 还可以让失败恢复、预算终止和安全拒绝测试保持确定性。

## 后果

- 当前结果不能代表真实模型任务成功率。
- 本机子进程不是针对恶意代码的完整沙盒。
- 领域模型和事件格式会作为后续 LLM Provider、FastAPI 与 Web UI 的稳定边界。
