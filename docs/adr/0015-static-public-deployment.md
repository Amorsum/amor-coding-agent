# ADR 0015：静态公网发布与自定义域名

## 状态

已接受，随 `v0.15.0` 实施。

## 背景

本地工作台能够读取仓库、访问 Provider 凭据并启动隔离任务，因此不能直接暴露到公网。`v0.14.0` 已经可以重新构造脱敏快照，但从本地产物到公网托管之间仍缺少一个可验证的最小发布边界。

## 决策

- 公网只发布静态快照，不部署 FastAPI 工作台、任务执行接口、Docker 控制面或 Artifact 原始目录。
- `stage-showcase` 只接受已经通过清单验证的 16 位快照 ID，并要求再次显式确认公开。
- 暂存目录只允许 `index.html`、`showcase.json` 和 `manifest.json`。发现 `.env`、源码或任何未知条目时立即拒绝。
- 三个文件逐一写入独立部署目录，完成后重新比对清单和 SHA-256，防止暂存过程引入变化。
- `.openai/hosting.json` 只声明托管平台支持的 `out/` 为静态目录，不配置运行时能力、环境变量、数据库或私有网络绑定。
- 正式自定义域名为 `amor.amorsum.top`。域名记录由 DNS 托管方配置，托管平台负责站点证书和发布版本。
- 每次线上更新都必须重新导出、确认、暂存、保存版本并部署；本地产物变化不会自动修改线上页面。

## 结果

公开页面可以独立托管和引用，同时本地 Coding Agent 的高权限能力继续限制在 loopback 服务内。代价是当前公网只提供只读实验证据，不提供任务提交、实时进度或 Artifact 浏览功能。
